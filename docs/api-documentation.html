Computers

/computers

Manage computers in the system. Each computer has a name, MAC address, optional IP, and can be assigned to a group, boot image, and writeback disk.

Request Body

macstringrequired@IsString()

Manage storage resources used for PXE boot images and writeback disks. Each resource has a type (BOOT_IMAGE or WRITEBACK), a file path, and an optional iSCSI IQN suffix.

Wake-on-LAN

/wol

Remote power management via Wake-on-LAN magic packets and remote shutdown. Uses PowerShell scripts under the hood.

POST /wol/turn-on Wake up a computer ▼

Description

Sends a Wake-on-LAN magic packet to the specified MAC address using a PowerShell script.

Request Body

FieldTypeRequiredDescription

PXE Boot

HTTP Boot

PXE network boot endpoints. Generates iPXE boot scripts dynamically based on computer MAC address and serves boot files over HTTP.

GET /boot Get iPXE boot script ▼

Description

Generates a dynamic iPXE boot script for a computer identified by its MAC address. Looks up the computer in the database to find its assigned boot image and writeback disk (falling back to group defaults), then returns an iPXE script with the appropriate iSCSI targets.

Query Parameters

ParamTypeRequiredDescription
macstringrequiredMAC address (format: AA:BB:CC:DD:EE:FF)

Response (200) - Content-Type: text/plain

#!ipxe # Dynamic boot script generated for the computer set server-ip <server-ip> set iscsi-iqn <iqn-base> sanhook --drive 0x81 iscsi:<target> sanboot --no-describe iscsi:<target>

Error Response (404)

"Computer not found"
GET /* Serve boot files (catch-all) ▼

Description

Catch-all route that serves static files from the /files/ directory. Used by PXE clients to download boot files (iPXE binaries, kernels, etc.).

Response

200: Raw file content with appropriate content type
404: File not found
